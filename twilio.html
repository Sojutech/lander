SMS Opt-In Consent Documentation - Verbal Consent Method

Business Overview

Business NameSojutech
Use CaseTransactional - sending links to digital contracts for clients to review, sign, and return digitally
Opt-In MethodVerbal consent obtained during a phone call with the client prior to any SMS being sent
Message FrequencyOne message per transaction (contract delivery)

Verbal Consent Script

The following script is used by representatives when obtaining verbal SMS consent from clients:

Agent: "Before we wrap up, I'd like to send your contract to you via text message so you can review and sign it digitally at your convenience. Would you consent to receiving one SMS from us for this purpose? Please note that standard message and data rates may apply, and you can reply STOP at any time to opt out."

Client: "Yes, that's fine." (or equivalent verbal confirmation)

Agent: "Thank you. You'll receive a text shortly with a secure link to your contract. As a reminder, you can reply STOP to that message at any time if you'd like to opt out."

Consent Recording Process

Upon receiving verbal consent, the agent immediately logs the following details in the CRM:

  • Client full name
  • Client phone number
  • Date and time of call
  • Confirmation that verbal consent was given

No SMS is sent prior to this consent being logged.

Opt-Out Instructions

Clients are informed of opt-out options both during the call (see script above) and via the SMS messages themselves. Every message includes opt-out instructions. Clients may reply STOP at any time to opt out, or reply HELP for assistance.

Confirmation Message

After verbal consent is obtained, the client receives the following confirmation text before the contract link is sent:

You have opted in to receive SMS from [Company Name]. Msg & data rates may apply. Reply STOP to opt out or HELP for help.

Sample Contract Delivery Message

Hello [Client Name], please review and sign the following document: [Link]. Thank you! - [Company Name]. Reply STOP to opt out.
